CWIT External Visitor Pass Request Process Flow |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  | 
1. External Visitor  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  | 
External visitor submits visitor details through the Visitor Management Portal  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  | 
⬇️ |  |  |  |  |  |  |  |  |  |  |  | 
2. Line Department Authorized Approver/HOD |  |  |  |  |  |  |  |  |  | 
Review the request. |  |  |  |  |  |  |  |  |  | 
Verify the business requirement and authorize the visit. |  |  |  |  |  |  |  |  |  |  | 
Forward the approved request to the Security Control Room (SCR). |  |  |  |  |  |  |  |  |  |  | 
⬇️ |  |  |  |  |  |  |  |  | 
3. Security Control Room (SCR) |  |  |  |  |  |  |  |  |  | 
Review visitor details and conduct necessary security screening. |  |  |  |  |  |  |  |  |  |  |  |  |  | 
Verify visit purpose, access requirements, and any restrictions. |  |  |  |  |  |  |  |  |  |  |  |  |  | 
Grant security clearance and forward the request to the Visitor Management Cell / Pass Section. |  |  |  |  |  |  |  |  |  |  |  | 
For VIP, Government, Customer, or Special Guests, notify LMV 2 Gate and relevant stakeholders in advance. |  |  |  |  |  |  |  |  |  |  |  |  |  | 
 |  | ⬇️ |  |  |  |  |  |  |  |  |  |  |  |  |  | 
4. Visitor Management Cell / Pass Section |  |  |  |  |  | 
Issue the appropriate visitor pass based on the approved access level. |  |  |  |  | 
Notify LMV 2 Gate and maintain visitor records. |  |  |  |  | 
⬇️ |  | 
5. LMV 2 Gate/People Access Point |  | 
Verify visitor identity (NIC/Passport). |  |  |  | 
Conduct security checks if required. |  | 
Grant entry and direct the visitor to the designated location. |  | 
 | ⬇️ |  | 
6. Visitor Departure |  | 
Visitor returns the pass at the pass securition and collect NIC/PP point. |  | 
Pass Section/Security records the exit and closes the visit record. |  |
