Design the FIRST / GLOBAL LANDING PAGE for the CWIT Visitor Management System.

IMPORTANT:
Use the provided Excel Sheet 0 as the PRIMARY STRUCTURAL REFERENCE.
Preserve the information hierarchy, sections, wording, and overall concept shown in Sheet 0.
Do not redesign the information architecture into a different page.

However, elevate the visual design using expert enterprise UI/UX principles so the final result looks like a professionally designed production system.

====================================================
CORE PURPOSE
====================================================

This is the first page displayed when a person enters the CWIT Visitor Management Portal.

The page must immediately communicate:

"Welcome to the Visitor Management Portal"

and the concept:

"Managing Visitors, Protecting CWIT"

The page then guides the person toward the correct requester journey:

INTERNAL REQUESTER
or
EXTERNAL REQUESTER

The page must feel like the official digital entrance to a secure port facility.

====================================================
DESIGN PHILOSOPHY
====================================================

Design language:

Premium Enterprise + Port Security + Modern Spatial UI

Think of the interface as:

"Digital Security Gate of a Major Container Terminal"

NOT:
- a generic SaaS landing page
- a marketing website
- a cyberpunk interface
- a gaming interface
- a cryptocurrency dashboard

The UI should communicate:
SECURITY
TRUST
CONTROL
PROFESSIONALISM
SIMPLICITY
EFFICIENCY

====================================================
BACKGROUND
====================================================

Create a sophisticated full-screen port environment.

Use a dark cinematic CWIT port atmosphere with:

- subtle container terminal
- cranes in the distance
- controlled access gate
- port buildings
- faint maritime horizon
- very subtle security-grid geometry

The background should be atmospheric rather than distracting.

Add a dark translucent overlay so the foreground content remains extremely readable.

Use restrained blue/cyan illumination inspired by modern security systems.

Avoid excessive neon.

====================================================
HEADER
====================================================

Follow the header structure shown in Sheet 0.

Create a premium minimal navigation/header.

LEFT:
CWIT logo / official branding

Beside logo:

"Visitor Management Portal"

RIGHT:
Keep only the navigation/actions that exist or are implied by Sheet 0.

Do not invent a large navigation menu.

Header should have:
- subtle transparency
- thin bottom border
- soft backdrop blur
- excellent spacing

====================================================
HERO / WELCOME SECTION
====================================================

Follow Sheet 0's structure.

Display prominently:

"Welcome to the Visitor Management Portal"

Below it:

"Managing Visitors, Protecting CWIT"

Then a concise supporting statement explaining that the portal provides secure visitor request and access management for Colombo West International Terminal.

Typography:
- large modern heading
- strong but elegant
- highly readable
- professional enterprise typography
- subtle text hierarchy

Do NOT make the heading excessively huge.

====================================================
REQUESTER SELECTION
====================================================

This is the main interactive area.

Preserve the two-path structure from Sheet 0.

Create two visually balanced premium selection panels/cards.

--------------------------------------------
INTERNAL REQUESTER
--------------------------------------------

Title:

"I am an Internal Requester"

Supporting label:

"CWIT Employee"

Short description:

"For CWIT employees and authorized department users."

Use an appropriate professional icon such as:
employee + ID badge / organization / building.

Primary action:

"Continue"

The entire card should be clickable.

Hover:
- slight elevation
- subtle blue glow
- border illumination
- smooth transition
- icon movement

--------------------------------------------
EXTERNAL REQUESTER
--------------------------------------------

Title:

"I am an External Requester"

Supporting label:

"External Visitor / Organization"

Short description:

"For external companies, organizations and visitors."

Use an appropriate icon such as:
visitor / organization / external user.

Primary action:

"Continue"

The entire card should be clickable.

Hover:
- slight elevation
- subtle blue glow
- border illumination
- smooth transition

====================================================
VISUAL RELATIONSHIP
====================================================

Do not make one requester type visually more important than the other.

Both paths must have equal visual weight.

Create a clear visual separation between them.

Possible treatment:

             WHO ARE YOU?

    ┌─────────────────┐    ┌─────────────────┐
    │                 │    │                 │
    │   INTERNAL      │    │   EXTERNAL      │
    │   REQUESTER     │    │   REQUESTER     │
    │                 │    │                 │
    │  CWIT Employee  │    │ External User   │
    │                 │    │                 │
    │   [ Continue ]  │    │   [ Continue ]  │
    └─────────────────┘    └─────────────────┘

The two cards should feel like two secure access gates.

SPATIAL UI DETAILS
====================================================

Use subtle depth:

- layered glass panels
- soft background blur
- thin borders
- realistic shadows
- restrained glow
- slight perspective/depth
- elegant micro-interactions

The cards can have a subtle 3D spatial effect when hovered.

Do NOT use heavy 3D objects.

====================================================
COLOR SYSTEM
====================================================

Primary:
Deep navy / midnight blue

Secondary:
CWIT-inspired blue

Accent:
Subtle cyan / electric blue

Text:
White / cool white

Secondary text:
Cool gray

Use accent lighting sparingly.

====================================================
UX REQUIREMENTS
====================================================

The user must understand the page immediately.

The visual hierarchy must be:

1. CWIT / Portal identity
2. Welcome message
3. "Managing Visitors, Protecting CWIT"
4. Choose requester type
5. Internal / External action

Do not overload the screen.

No dashboard statistics.

No unnecessary charts.

No marketing cards.

No unnecessary animations.

No login fields on this page.

No visitor request form on this page.

The landing page is ONLY the gateway.

====================================================
RESPONSIVE DESIGN
====================================================

Desktop:
Two cards side-by-side.

Tablet:
Cards remain comfortable and readable.

Mobile:
Stack the two cards vertically.

Maintain the same hierarchy and visual quality.
