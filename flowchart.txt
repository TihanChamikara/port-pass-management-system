# 2. FLOWCHART STANDARD

Use conventional software engineering flowchart notation.

### START / END

Use:

**Terminator / Oval**

Example:

`Start`

`End`

### PROCESS

Use:

**Rectangle**

Example:

`Submit Visitor Request`

### DECISION

Use:

**Diamond**

Example:

`Request Valid?`

Branches must be clearly labelled:

`Yes`

`No`

### INPUT / OUTPUT

Use:

**Parallelogram**

Example:

`Enter Visitor Details`

### DATABASE

Use:

**Database / Cylinder**

Example:

`PostgreSQL Database`

### DOCUMENT

Use:

**Document Symbol**

for:

* Generated pass
* Reports
* Documents

### CONNECTORS

Use:

* Arrow connectors
* Clear direction
* No crossing lines where avoidable
